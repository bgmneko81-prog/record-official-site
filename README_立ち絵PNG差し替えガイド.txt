■ 基本
サイト本体はすべて編集済みです。HTMLやJSを編集する必要はありません。
透過PNGを「RECORD_site_v15/assets/images/」へ置くだけです。
元の作品をJPGへ変換したり、ファイル拡張子だけを偽装する必要はありません。

■ 保存と確認
1. 対象画像を PNG 形式で用意する。透過を維持したい場合は背景透過PNG。
2. 上の一覧と一字一句同じファイル名に変更する。
3. assets/images にコピーする。
4. index.htmlをブラウザで開く。再表示されない場合 Ctrl+F5 で更新する。
5. 人物詳細ページと怪異切り替えボタンも確認する。
