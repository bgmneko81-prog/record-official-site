CHAPTER 01 / WORLD / ANOMALIES

世界と怪異

FILE / 08-01

伊良坂町と彼岸の秘密

伊良坂町は、現世である「此岸」と死者の世界に通じる「彼岸」の境界が、もともと不安定な土地である。

そのため、特定の条件がそろうと、生きた人間でも彼岸に迷い込むことがある。

町で長年繰り返されている失踪事件の一部は、この現象に関係している。

彼岸へ渡った人間が、必ずしも帰還できないわけではない。

FILE / 08-02

「十三段目」の発生条件

伊良坂高等学校の屋上へ続く階段に存在する怪談。

この怪異が成立する条件には、次の二つが関わっている。

階段の段数を数えること。 そして その行為を別の人間に観測されること。

条件が重なると、通常は存在しない階へと入り込み、彼岸に迷い込んでしまう。

プロローグでは、主人公が階段を数えているところを幼なじみに目撃され、二人とも彼岸へ移動する。

FILE / 08-03

写世（うつしよ）

湊人（明人の兄）がかつて使用していた特殊なカメラ。

写真を撮影することで、その場所を一時的に彼岸側へと変化させ、通常の世界では見えない文字や道具を発見できる。

彼岸で手に入れた特定の道具を、此岸へ持ち帰ることもできる。

プロローグでは主人公が彼岸の教室で発見する。その時点では、湊人の持ち物だったことやカメラの正体は明かされない。

FILE / 08-04

みどりさまの真実

穂澄神社に祀られている豊作の神。

かつて人間との間に、敬意と奉納を受ける代わりに豊かな実りを与えるという約束が存在した。

しかし時代とともに信仰や奉納が減り、神は人間が約束を破ったと考えるようになる。

かつて人々に恵みを与えていた神は、次第にその怒りを募らせていく。

本来の呼び名「実りさま」が時代とともに訛り、「みどりさま」になったという由来を持つ。

FILE / 08-05

黒幕の計画

みどりさまは、彼岸に生きた人間を集め、その魂を喰らうことを企てている。

魂を失った人間の肉体を怪異の器として利用し、彼らを率いて此岸へ進出する。

最終的な目的は、百鬼夜行によって此岸と彼岸の関係を逆転させること。

そのために、湊人の存在と人を救おうとする意志までも利用している。

CHAPTER 02 / INVESTIGATION / EVENTS

事件と手がかり

FILE / 08-06

湊人と謎の少年の秘密

湊人（明人の兄）は、伊良坂町の失踪事件の謎を解明しようとしていた。

しかし調査の過程で、みどりさまに欺かれ、「黄泉戸喫（よもつへぐい）」を行ってしまう。

その結果、湊人の存在は分かたれ、その半身が謎の少年の姿となった。

少年は不完全な記憶しか持たず、主人公が自分の弟であることも認識していない。

しかし湊人が持っていた「人を助けたい」という意志は残っている。

少年は迷い人を此岸へ帰そうとしているが、みどりさまによって帰還経路の行き先がすり替えられていることには気づいていない。

一方、みどりさまはその善意を利用し、人々を彼岸の一か所へ集めている。

また、湊人に似た人物の目撃談にも黒幕の介入がある。

少年の正体と「観測」の関係に関する詳しいルールは、今後詰める。

これは物語の根幹に関わる秘密として扱う。

FILE / 08-07

灯寄せ（ひよせ）

彼岸へ迷い込んだ人々が集まる場所。

少年は人々を救うために行動しているが、その結果が黒幕による生者の収集に利用されている。

「灯りを頼りに集まる」という救いの意味と、「魂を集める」という恐ろしい意味を持つ場所。

具体的な外観や内部構造は未決定。

FILE / 08-08

常世石（とこよいし）

此岸と彼岸をつなぐ仕組みに関わる重要な石。

主人公が物語の終盤で、二つの世界をつなぐバイパスを断ち切ろうとする展開に関係する。

ただし、常世石自体が通路なのか、接続を維持する要石なのか、破壊や解除の具体的な方法はまだ確定していない。

FILE / 08-09

プロローグの詳細展開

主人公に手がかりを残したのは、実は謎の少年。ただし、この事実はプロローグでは明かされない。

  1. 日常の学校生活の中で、二人の生徒が「十三段目」と湊人に似た人物の目撃談を話す。
  2. 湊人の特徴に関する話を聞いた主人公が、二人に詳しい話を尋ねる。
  3. 幼なじみが危険な場所へ向かおうとする主人公を心配する。
  4. 主人公が放課後、屋上階段で段数を数える。
  5. 後を追ってきた幼なじみがその姿を目撃し、怪談の条件が成立する。
  6. 二人は彼岸へ迷い込む。
  7. 探索の途中で離ればなれになった主人公が「虚面」に遭遇する。
  8. 主人公は教室に隠れ、物音を立てずに怪異をやり過ごす。
  9. その教室で古いカメラ「写世」を発見する。
  10. 撮影によって、普段は見えない文字が浮かび上がる。
  11. 文字を手がかりに幼なじみを探し、閉じ込められた部屋を見つける。
  12. 「鍵は、時の止まった場所に」という手がかりから、止まった時計の裏にある鍵を見つける。
  13. 幼なじみを救出し、二人で現世への帰還を目指す。

CHAPTER 03 / CHARACTER / SECRETS

登場人物の秘密

FILE / 08-10

黒瀬朱音の秘密

朱音は生まれつき怪異を引き寄せる体質を持つ。しかし本人には怪異が見えず、その体質にも気づいていない。

幼少期のいじめはこの体質と関係しており、みどりさまも関与していた。具体的な仕組みと関与の方法は未確定。

幼い頃に朱音を助けたのは明人。朱音にとって忘れられない出来事であり、明人への憧れと恋愛感情につながっているが、明人自身は覚えていない。

朱音の対人洞察力は怪異による能力ではなく、本人の経験から身についたもの。

FILE / 08-11

月森澪の正体と覚醒

澪は彼岸の住人。人間の身体を「器」として怪異の魂が宿った存在であり、元の身体の持ち主本人ではない。

澪の魂は「穢れのない澄んだ状態」だった。具体的な理由と性質の影響はまだ未確定。

物語序盤では澪自身もその正体を知らず、自分の過去も覚えていない。正体を知った際には、仲間に嫌われないかを心配するが、全員に受け入れられる。

その後、仲間を守りたい思いから守護・結界の力が覚醒する。淡く半透明な光の障壁を展開し、怪異の攻撃から仲間を守る。治癒・浄化などの能力は現時点では設定していない。

FILE / 08-12

美原湊人の失踪の経緯

美原湊人は美原家に伝わる「導き手」の役割を担っていた。神代家とは長い協力関係にあり、神代怜は親友で信頼できる相棒。

みどりさまが仕組んだ捜索依頼を受けて向かった先で、湊人は本当に助けを必要としていた人物を救助した。救助された人物は罠を知らず、感謝のお礼として偶然持っていたリンゴを渡す。

湊人がそのリンゴを口にしたことで「黄泉戸喫（よもつへぐい）」が成立。異変を自覚する前に彼岸へ引き込まれ、その存在は分かたれた。リンゴは禁断の果実を象徴するが、詳しい仕組みは未確定。

湊人と救助された人物の善意が、豊作の神であるみどりさまに利用された事件。湊人は罠を予見していたわけではない。

FILE / 08-13

謎の少年の道案内と結末

謎の少年は、湊人の存在から分かれた半身。少年自身はその正体を知らず、湊人としての記憶も持っていない。

少年は善意で迷い人を正しいはずの帰還経路へ案内している。しかし、みどりさまが行き先を変更したため、実際には人々をみどりさまのもとへ送り込んでしまっていた。

少年と明人は、みどりさまから同時に真実を知らされる。少年は深く後悔するが、明人は人を救いたいという思いが本物だったことを伝え、少年は再び立ち上がる。

物語終盤、少年は湊人の半身であることを知り、元の存在へ戻ることを受け入れる。明人との間に生まれた友情は本物だが、少年としての独立した存在は消える。

湊人へ戻った後、湊人には少年として過ごした間の記憶が一切残らない。明人は少年に別れを告げ、帰ってきた湊人と再会する。
